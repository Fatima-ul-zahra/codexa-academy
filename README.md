# 🎓 Codexa Academy

Codexa Academy is a modern full-stack IT education platform designed to provide students with structured programming and web development learning programs.

The platform features a responsive React.js frontend and a Node.js + Express.js backend connected to MongoDB for data management. It provides information about courses and programs, learning tracks, mentorship, instructors, testimonials, FAQs, registration, and contact functionality.

## 🚀 Tech Stack

* React.js — Frontend
* Node.js — Backend runtime
* Express.js — Backend framework & REST APIs
* MongoDB — Database
* JavaScript — Application development
* Git & GitHub — Version control
* Netlify — Frontend deployment

## ✨ Features

* Responsive and modern UI
* Academy and program information
* Course and learning-track sections
* Student-focused learning experience
* Mentorship information
* Instructor/founder section
* Testimonials
* FAQ section
* Registration/waitlist functionality
* Contact functionality
* REST API-based backend
* MongoDB database integration
* Full-stack frontend and backend architecture

## 🎯 Purpose

The goal of Codexa Academy is to create a professional online platform where students can explore programming programs, understand available learning paths, and connect with the academy.
